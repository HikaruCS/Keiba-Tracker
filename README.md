# Keiba-Tracker
ブラウザ上で馬券の収支の記録・管理ができるWebサイトです

## サイトのURL
こちらからサイトにアクセスすることができます。<br>
https://hikarucs.github.io/Keiba-Tracker/

## 開発の背景
このサイトを作ろうと思ったきっかけは、以前学んだHTML、CSS、JavaScriptなどのフロントエンド系の言語を実際の開発を通じて何かアウトプットしたかったからと、そのアウトプットとして、自分が馬券を購入した際に詳細な情報 (日付、競馬場、レース、券種など) も記録できる競馬収支管理システムを作りたいと思ったからです。

## 開発の際の工夫点
開発を始めた際、まだデータベースに関する知識がなかったため、代替案としてlocalStorageを用いて馬券のデータを保存するようにしました。<br>
また、localStorageにデータを保存する際のキー作成の方法も工夫しました。これにより同じレースで複数種類の馬券を購入しても問題なくデータを保存できます。<br>
さらに、どのデバイスでも使用できるようにレスポンシブ対応をしました。Bootstrapを用いることでよりスムーズにレスポンシブ対応に取り組めました。
